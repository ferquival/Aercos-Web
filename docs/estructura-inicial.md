# Estructura inicial del proyecto

## Árbol de directorios

```text
.
├── index.html
├── css/
│   └── main.css
├── js/
│   └── main.js
├── img/
├── fonts/
├── icons/
├── docs/
│   └── estructura-inicial.md
├── README.md
└── .gitignore
```

## Elementos

- `index.html`: punto de entrada de la página web. Incluye la estructura HTML mínima y las referencias al archivo de estilos y al script principal.
- `css/`: directorio destinado a los estilos del sitio.
- `css/main.css`: archivo de estilos globales. Actualmente no contiene reglas visuales.
- `js/`: directorio destinado a los scripts del sitio.
- `js/main.js`: archivo principal para la lógica JavaScript. Actualmente está vacío.
- `img/`: directorio para imágenes y recursos gráficos rasterizados.
- `fonts/`: directorio para archivos de fuentes tipográficas locales.
- `icons/`: directorio para iconos y recursos vectoriales.
- `docs/`: directorio para la documentación del proyecto.
- `docs/estructura-inicial.md`: este documento, que registra la estructura inicial del proyecto.
- `README.md`: archivo reservado para la documentación general del proyecto. Actualmente está vacío.
- `.gitignore`: archivo reservado para definir los archivos y directorios que Git debe ignorar. Actualmente está vacío.
