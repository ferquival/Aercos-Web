# Referencias visuales de Aercos

Esta carpeta centraliza las referencias visuales aprobadas que orientan el sistema de diseño y la evolución de la interfaz de Aercos. Su objetivo es conservar una identidad visual coherente entre páginas, componentes y futuras fases del proyecto.

## Organización

- `referencias/branding/`: logotipo, aplicaciones de marca y referencias de identidad.
- `referencias/hero/`: composiciones y recursos visuales para cabeceras.
- `referencias/iconografia/`: lenguajes iconográficos y diagramas técnicos.
- `referencias/tarjetas/`: referencias de tarjetas, módulos y contenido destacado.
- `referencias/navegacion/`: patrones de navegación y menús.
- `referencias/animaciones/`: ejemplos de movimiento, transiciones y microinteracciones.
- `referencias/fondos/`: texturas, patrones y recursos de fondo.
- `referencias/formularios/`: referencias de formularios y estados de interacción.
- `referencias/tipografia/`: sistemas tipográficos, jerarquías y composición editorial.
- `referencias/ui-general/`: referencias generales de interfaz que no pertenezcan a otra categoría.

## Proceso de uso

Cada referencia añadida se analizará antes de influir en la interfaz. El análisis identificará sus principios de diseño, los elementos adaptables a Aercos y las restricciones necesarias para evitar una reproducción literal. Las conclusiones se registrarán en `decisiones-diseno.md`.

Las referencias se usan únicamente como inspiración. Ninguna se copiará literalmente. Antes de cambios relevantes en la interfaz, se revisará el conjunto de referencias aprobadas y el registro de decisiones; una única imagen no será suficiente para definir una mejora de diseño.
